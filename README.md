# Ling-3.0-flash-Fin vs 基座 Ling-3.0-flash 独立实测

对蚂蚁百灵金融增强模型 Ling-3.0-flash-Fin 与其通用基座 Ling-3.0-flash 的对照测试。
同架构、同 124B 总参 / 5.1B 激活、同材料、同参数（temperature=1, top_p=0.95），唯一变量是金融训练。

**样本：441 轮有效数据，8 类任务，2 个模型。测试对象：微软 FY26 Q4 财报、宁德时代 2025 年报（均为公开一手材料）。**

> 说明：本仓库为一篇有偿商单测评的配套数据与代码。测试方法、数据和结论由作者独立完成。
> 公开这些原始记录，是为了让任何人都能自行复核下面的结论——包括推翻它。

## 核心结论

- **441 轮零答错。** 所有失败都是「不作答」（返回空），从无错误答案。
- **准确率上未测出金融增强的优势。** 建模型、辨口径、抗幻觉、跨源推理，两模型通过率持平。
- **唯一显著差异：长输出任务上金融版更易静默失败。** 研报撰写任务金融版 8/43（18.6%）返回空，基座 0/48。全局 7.9% vs 1.3%，p=0.0009（Fisher 与置换检验一致）；但排除长输出任务后不显著（p=0.082）。
- **失败可预测：** 当 `reasoning_tokens / completion_tokens > 0.7` 时，返回空的概率大幅上升。
- **长上下文直投 > 工具检索：** 同一道题，把 15 万 token 一次性喂入（不给工具）比让模型自行检索更准（100% vs 93%）、快 2–4 倍、调用少 9 倍。
- **幻觉测试满分：** 问及材料中不存在的数字时，两模型均明确拒答，从不编造。

## 目录

- `code/` — 执行器与评分脚本
  - `runner.py` 单轮 agent 执行器（工具循环 + 计量 + 限流重试）
  - `driver.py` 批量驱动（含续跑逻辑）
  - `tasks.py` 8 类任务定义
  - `grade.py` 自动评分（标准答案可执行判定）
  - `extract_materials.py` 财报文本抽取
- `results/`
  - `graded.json` 每轮评分结果（模型/任务/判定/token/耗时/工具轨迹）
  - `results.jsonl` 每轮原始计量
- `logs/` — 441 轮 `log.json`，每轮含完整工具调用轨迹与 token 构成
- `conversations/` — **441 轮完整对话记录**，每轮含全部 prompt、模型完整回答、工具调用与返回
- `docs/`
  - `测评参数.md` **采样参数、agent 设定、材料构成、统计方法**（复现必读）
  - `测试设计-v2.md` 8 类任务的设计与验收标准
  - `扩样记录.md` 样本量变更与数据剔除的完整记录

## 如何复现

1. 在 OpenRouter 注册并获取 API key，设为环境变量 `OPENROUTER_API_KEY`（充值满 $10 才有 1000 次/天额度）。
2. 从下列公开来源下载材料，用 `extract_materials.py` 抽成文本：
   - 微软 FY26 Q4：microsoft.com/investor（IR 页面）
   - 宁德时代 2025 年报：巨潮资讯网 cninfo.com.cn
3. `python driver.py` 跑测，`python grade.py` 评分。

## 数据透明度（重要）

本测试过程中出现并已修正的问题，全部记录在 `docs/扩样记录.md`：

- **执行器早期有路径 bug**，导致 6 轮（全在金融版一侧）的工具调用失效，已剔除。剔除后「金融版调用次数是基座 2.4 倍」修正为约 1.7 倍。
- **F 任务样本量从每臂 24 扩至 48**，因初始 p 值（0.0496）临界；扩样在看到新数据前声明，最终结果如实报告。
- **两次触发 OpenRouter 每日额度上限**，受影响轮次已剔除。
- 「多份研报」以公司自发布材料（transcript / slides / 10-Q）替代，因卖方研报付费不公开。

本地路径、Windows 用户名等信息在发布前已统一脱敏为 `<project>` / `<user>`。
