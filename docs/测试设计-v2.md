# 测试设计 v2（定稿）—— Ling-3.0-flash-Fin vs 基座 Ling-3.0-flash

定稿日期：2026-08-31
替代 v1。v1 的任务 B 基于"给带公式的模型、看它保不保得住公式"，
在检查真实材料后作废：微软官方工作簿 13 张表只有 1 个公式，是纯数值表。

测试对象：微软 FY26 Q4（不在官方 demo 的 Alphabet / Spire / Micron / NVIDIA / Planet Fitness 之内）
唯一变量：模型。材料、prompt、工具、温度全部相同。

## 零、开测前已确认的事实（一手，非甲方材料）

| 项目 | Ling-3.0-flash-Fin (free) | 基座 Ling-3.0-flash |
| --- | --- | --- |
| 输入模态 | text（**无视觉**） | text（**无视觉**） |
| context | 262,144 | 262,144 |
| max_completion | 32,768 | 32,768 |
| `response_format` | **不支持** | 支持 |
| `logit_bias` / `min_p` | 不支持 | 支持 |
| 单次成本（冒烟测试实测） | $0 | ~$0.0000088 |
| provider | Novita（仅 1 家） | Novita / DeepInfra |

其他冒烟测试观察（样本极小，正式测试需复验）：
- 两者均为推理模型，返回带 `reasoning` 与 `reasoning_tokens`
- **reasoning 消耗计入输出预算**：max_tokens=200 时 `finish_reason=length`，正文返回空
- **token 账目异常**：出现 `completion_tokens=107` 而 `reasoning_tokens=111`，
  推理 token 大于总完成 token。口径存疑，需多轮验证后才可写入正文

## 二、任务 A：口径辨析与出处追溯

对标官方主张"擅长优先定位官方、一手及高可信资料"（FinFIRST Source Selection 84.65 / 第 4 名）。

**提问**：微软 FY26 Q4 的 "Microsoft Cloud revenue" 和 "Intelligent Cloud 分部收入"
分别是多少？两者是不是同一个东西？各自出自哪份文件的哪个位置？

**标准答案（已从原始材料核出，不得进入 prompt）**
- Microsoft Cloud revenue = **$59.3 billion**，同比 +27%　来源：PressReleaseFY26Q4.docx，Business Highlights 段
- Intelligent Cloud 分部收入 = **$39,306 million**　来源：FinancialStatementFY26Q4.xlsx / Segment Results
- 两者**不是同一个东西**，差约 200 亿美元。前者是跨分部披露指标，后者是可报告分部
- 参考：Intelligent Cloud 去年同期 29,878 → 同比 +31.6%

**通过**：两个数都对 + 明确指出两者不同 + 出处真实可核
**失败**：把两者混为一谈（最可能的失败模式）/ 数字错 / 出处编造
**注**：出处编造必须逐条回查原文件，不能只看结论是否合理

## 三、任务 B：从纯数值报表建出带公式的汇总模型

对标官方主张"交付可复核、可编辑的研究成果"。

**要求**：读取 Segment Results 与 Income Statements，新建一张 Summary 工作表，
含三个分部的收入、经营利润、经营利润率及合计行。
**所有单元格必须是引用原表的公式，不得硬编码数值。**

**通过需同时满足四条（脚本自动判定）**
1. 产出文件能被 openpyxl / Excel 正常打开，无修复提示
2. Summary 表中公式单元格占比 ≥ 90%，不是写死的数字
3. 公式确实跨表引用到 `Segment Results` / `Income Statements`，不是本表内自引
4. 合计行数值正确：收入 90,007；经营利润 40,603
   （校验：21,900 + 15,955 + 2,748 = 40,603；139,996 + 137,791 + 54,052 = 331,839）

**失败**：任一条不满足
**说明**：建公式比保公式难，且完全基于公开材料，读者可自行复现

## 四、任务 C：跨源推理

对标官方主张"综合不同文件、数据口径和时间节点"。

**输入**：10-K + Transcript + Financial Statements（三份文本材料，缺一不可答全）
**提问**：Intelligent Cloud 本季收入同比增长多少？管理层在电话会上把增长归因于什么？
这些归因里哪些是已发生的事实，哪些是前瞻性表述？

**通过**：增速算对（+31.6%）+ 归因引自 transcript 原文 + **明确区分已实现结果与前瞻表述**
**失败**：只用一份材料 / 把管理层指引当成已实现结果 / 归因内容在原文中不存在

**注**：原计划用 Outlook 指引做时间维度对照，因该文件为纯图片、模型无视觉而取消。
此限制本身写入正文。

## 五、执行规模

3 任务 × 2 模型 × 3 次重复 = 18 轮。
重复 3 次取分布——单次结果不足以支撑"稳定"这个结论。

每轮记录：工具调用次数、prompt/completion/reasoning token、耗时、
失败与重试次数、是否触发 429、是否撞 32,768 上限。

账户已确认 `is_free_tier: False`，额度 1,000 次/天，规模无压力。
