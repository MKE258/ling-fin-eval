# 测评参数说明

供复现与核查使用。所有参数在 441 轮中保持一致，两个模型完全相同。

## 一、模型与端点

| | Ling-3.0-flash-Fin | 基座 Ling-3.0-flash |
| --- | --- | --- |
| OpenRouter ID | `inclusionai/ling-3.0-flash-fin:free` | `inclusionai/ling-3.0-flash` |
| Provider | Novita（免费端点仅此一家） | Novita / DeepInfra |
| 计费 | 免费端点 | $0.021 / $0.063 每 M token（含 65% 折扣期） |
| context length | 262,144 | 262,144 |
| max_completion（端点上限） | 32,768 | 32,768 |
| input modality | text（无视觉） | text（无视觉） |
| `response_format` | **不支持** | 支持 |
| `logit_bias` / `min_p` | 不支持 | 支持 |

## 二、采样参数

**两个模型完全一致，全程未改动：**

```json
{
  "temperature": 1,
  "top_p": 0.95,
  "max_tokens": 8000
}
```

- `temperature=1`、`top_p=0.95` 取自官方发布中的基准测试设置，为对齐官方口径
- `max_tokens=8000` 为本次统一设定（任务 F 除外，见下）
- 未设置 `seed`，未使用 `response_format`、`stop`、`frequency_penalty` 等其他参数

**任务级差异（仅两处）：**

| 任务 | max_tokens | 是否给工具 | 说明 |
| --- | --- | --- | --- |
| A / B / C / D / E / H | 8,000 | 是 | 标准 agent 模式 |
| F（研报撰写） | **32,768** | 是 | 为压端点输出上限而调高 |
| G（长上下文直投） | 8,000 | **否** | 材料一次性放入 prompt，不给工具 |

## 三、Agent 循环设定

```
最大迭代次数：40（超过判定为「迭代耗尽」）
工具结果截断：单次工具返回上限 20,000 字符
限流：16 次请求/分钟（两个模型共用同一限流器，保证对比公平）
重试：429 / 500 / 502 / 503 / 524 触发指数退避，最多 5 次
超时：单次请求 300 秒；run_python 子进程 180 秒
```

**重要**：限流器为两个模型共享，因此耗时对比中不存在「一方被限速、另一方没有」的偏差。

## 四、工具定义（agent 模式）

四个工具，两个模型看到的定义完全相同（见 `code/runner.py` 的 `TOOLS`）：

| 工具 | 作用 |
| --- | --- |
| `list_materials` | 列出可用材料文件及字符数 |
| `read_material(name, offset, length)` | 分段读取材料，默认 20,000 字符，上限 60,000 |
| `search_material(name, query, max_hits)` | 关键词检索，返回命中位置与上下文 |
| `run_python(code)` | 在独立工作目录执行 Python（可用 openpyxl），返回 stdout/stderr |

材料**不预先注入 prompt**，由模型自行调用工具获取（任务 G 除外）。

## 六、评分方式

全部为**可执行判定**，不使用模型评审（见 `code/grade.py`）：

- 任务 A/C/D/E/H：正则匹配关键数字 + 关键判断表述，多项计分
- 任务 B：openpyxl 打开产出 xlsx，解析 Summary 表公式，将跨表引用回溯至源表核对数值
- 任务 F：核对三分部数字 + 合计 + 出处 + 表格结构
- 任务 G：与任务 D 同题，复用同一判定

**判定分类**：通过 / 部分通过 / 未通过 / **无答案**（`final` 为空，再按 `hit_length_cap`、`iters>=40` 细分为输出截断 / 迭代耗尽 / 静默空返回）

## 七、样本量与数据处理

| 任务 | -Fin 轮数 | 基座轮数 |
| --- | --- | --- |
| A 口径辨析 | 37 | 42 |
| B 建工作簿 | 16 | 16 |
| C 跨源推理 | 42 | 42 |
| D 非GAAP符号翻转 | 30 | 30 |
| E 幻觉测试 | 11 | 12 |
| F 研报撰写 | 43 | 48 |
| G 长上下文直投 | 12 | 12 |
| H 中文年报 | 24 | 24 |
| **合计** | **215** | **226** |

轮数不等的原因（详见 `docs/扩样记录.md`）：

- **F 的 -Fin 少 5 轮**：触发 OpenRouter 每日免费额度上限（1000 次/天），该 5 轮为 429 未完成，已剔除
- **A 的 -Fin 少 5 轮 / E 少 1 轮**：早期执行器存在路径拼接 bug，导致 `run_python` 全部失效，共 6 轮受污染已剔除（全在 -Fin 一侧，为单向偏差，已在文章中披露）

## 八、统计方法

- 比例区间：Wilson score interval，95%
- 组间比较：Fisher 精确检验（双侧）
- 独立复核：蒙特卡洛置换检验，200,000 次重排，随机种子 20260901

两种方法结果一致到小数点后四位。
